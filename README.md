# RAG 学习实验室 · 读 / 切 / 存 / 检

一个用于学习 RAG（检索增强生成）核心流程的交互式单页网站：
把「文档加载 → 父子块拆分 → 向量化入库 → 混合检索」四个步骤，用大白话批注 + 可动手的实验台讲清楚。

## 打开方式

**方式一（最简单）**：直接双击 `index.html`，任何现代浏览器都能离线打开。

**方式二（本地服务器）**：

```bash
python3 -m http.server 8791
# 浏览器访问 http://localhost:8791
```

## 页面里有什么

| 章节 | 内容 | 互动实验台 |
|---|---|---|
| ① 读 | 多格式文档加载、OCR、元数据标签 | 收书窗口：点文件看加载器怎么接、盖什么章 |
| ② 切 | 父子块两层拆分：「用小的找，用大的答」 | 拆分台：切父块 → 切子块 → 提问命中 → 弹出父块 |
| ③ 存 | BGE-M3 稠密 + 稀疏双向量、Milvus 表结构 | 双向量透视仪：一句话的两种向量化 + 相似度对比 |
| ④ 检 | 混合检索、WeightedRanker、重排序 | 检索模拟台：两路召回 → 融合去重 → 重排 Top-M |
| 全套代码 | 按数据流顺序拼装的完整参考实现（含 VLM 看图说话版 PDF 加载器） | — |

> 页面中的分数与向量为教学模拟，真实数值由 BGE-M3 / bge-reranker-large 计算；
> 完整的 Python 参考实现已内嵌在「全套代码」章节中，可复制运行。
